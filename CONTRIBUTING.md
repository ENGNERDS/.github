# Contributing

ENGINERDS is a small closed team. Our projects are developed privately, so we do not take outside contributions for now.

> [!NOTE]
> Members follow the full contributing guide in each project repository, which covers the branch, pull request and review workflow and the exact commands for that project.

## How we work

- Every change goes through a branch and a pull request, even a one-line fix. Nobody pushes to `main`.
- Each pull request is small, focused and linked to the issue it closes.
- Pull request titles start with a prefix such as `feat:`, `fix:` or `docs:`.
- Checks must pass and another member reviews the change before it merges.
- Whoever merges a change can explain every line of it.

## Secrets

Never commit or post a token, key or password. See [SECURITY.md](SECURITY.md) for what to do if one leaks.
