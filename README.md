# ENGNERDS/.github

Public organisation files for ENGINERDS.

The organisation's real name is ENGINERDS. It was created on GitHub as ENGNERDS (the "I" is missing), so the address stays `github.com/ENGNERDS`.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public organisation profile shown on [github.com/ENGNERDS](https://github.com/ENGNERDS) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct for every repository without its own |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide |
| [`SECURITY.md`](SECURITY.md) | Default security policy |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull request template |
| [`.github/CODEOWNERS`](.github/CODEOWNERS) | Who reviews changes to this repository |
| [`.github/workflows/`](.github/workflows/) | Markdown lint and a secret scan for this repository |

GitHub uses these files for any repository in the organisation that does not have its own copy. A project can override any of them by adding its own version.

## Changing this repository

Changes go through a pull request with a prefixed title (`docs:`, `ci:` or `chore:`) and green checks. Nothing secret is ever committed here.
